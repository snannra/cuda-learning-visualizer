Reading CUDA grids

A matrix layer shows the whole output. Block and tile layers each show one bounded grid, overlaid on the matrix to compare their sizes. Repetition is optional and off by default; these are geometric comparisons, not a CUDA execution simulation.

For the walkthrough kernel, block dimensions equal TILE × TILE. Other kernels can assign multiple output elements per thread.
